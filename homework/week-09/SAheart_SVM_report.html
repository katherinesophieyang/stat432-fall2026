SAheart: SVM kernel comparison

Data: 462 observations; response chd (0: 302, 1: 160); no missing values. Predictors are eight numeric measures plus binary famhist (Absent=1, Present=2). SVM is suitable for this binary outcome and can represent nonlinear boundaries; differing predictor scales make fold-wise standardization important. Predictors: sbp, tobacco, ldl, adiposity, famhist, typea, obesity, alcohol, age.

Design: Stratified five-fold CV (seed 43217); identical folds for all 20 candidates. Standardization is fit on each training fold only. Linear is the baseline; degrees 2-4 and radial kernels assess nonlinear boundaries. C uses a log-spaced grid; radial gamma is 0.01 or 0.1. Polynomial gamma=1/9 and coef0=1; other SVC settings are fixed at defaults (including equal class weights). Select the lowest mean fold misclassification rate; ties favor simpler settings. No separate test set is used.

Polynomial models fix gamma=1/9 and coef0=1. The radial grid varies C and gamma. C controls the margin/error tradeoff.

Cross-validation comparison

Preferred: polynomial, degree=2, C=0.1, gamma=1/9, coef0=1. Mean five-fold CV misclassification rate: 0.2686. The selected pipeline was refit on all 462 observations after selection; there is no independent test-set performance estimate.

Interpretation and limits: CV supports comparison within this prespecified grid, not a claim of external predictive performance. The response is moderately imbalanced (302 no CHD; 160 CHD), so the overall error rate should be read alongside class counts. The best setting may vary across samples; the grid does not establish that one kernel is universally superior.

The search used C=(0.01, 0.1, 1, 10, 100) for linear; C=(0.1, 1, 10) for polynomial degrees 2-4; and C=(0.1, 1, 10) crossed with gamma=(0.01, 0.1) for radial. All predictors were standardized fold-wise.
